# 안산햇빛교회 앱

말씀과 기도로 하나 되는 우리 교회 — 안산햇빛교회 성도용 웹앱(PWA)입니다.
설치 없이 주소로 열 수 있고, 갤럭시·아이폰 모두 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 기능

| 화면 | 내용 |
|---|---|
| 🏠 홈 | 오늘 날짜, 기도 시간 안내와 남은 시간, 이번 주 암송 말씀, 각 메뉴 바로가기, 교회 소식 |
| 📖 성경 | 개역한글 66권 읽기(이전/다음 장), **🔊 한글 듣기**, **English(ESV) 본문 + 영어 듣기**, 마지막 읽은 곳 기억, **1년 1독 통독표**와 진도율 |
| 🎙️ 말씀 | 이번 주 설교(유튜브 영상, 본문, 요약, 핵심 말씀), 지난 설교 목록 |
| ✍️ QT | 오늘의 본문과 묵상 질문, **나의 묵상·적용·기도 노트**(휴대폰에만 저장), 지난 QT |
| 🙏 기도 | **매일 오전 10시·오후 10시 기도 알림**, '기도했어요' 기록·연속 일수, 교회 공동 기도제목, 나만 보는 기도 제목 |
| 📰 주보 | 홈의 '이번 주 주보' 카드 → 주보 사진(누르면 크게, 확대·넘기기), PDF, 지난 주보 목록 |
| 📷 교회 앨범 | 홈의 '교회 앨범' 카드 → 달별 행사 앨범, 사진 크게 보기(이전/다음) |
| 📢 교회 | 공지사항, 다가오는 일정, 예배 시간, 오시는 길, 앱 설치 방법 |

- 오른쪽 위 **가A** 버튼: 글자 크기 3단계 (어르신용 큰 글씨)
- 한 번 열면 오프라인에서도 앱 화면이 열립니다 (성경 본문은 인터넷 필요)

## 기도 알림 (오전·오후 10시)

웹앱은 앱이 꺼져 있을 때 스스로 알람을 울릴 수 없어서, 두 가지를 함께 제공합니다.

1. **캘린더 알림 (권장, 가장 확실함)** — 기도 화면에서 한 번만 등록하면 휴대폰이 잠겨 있어도 매일 알림이 옵니다.
   - 아이폰·삼성 캘린더: `prayer-alarm.ics` 추가
   - 구글 캘린더: 오전/오후 버튼을 각각 눌러 저장
2. **앱 알림** — 앱이 열려 있을 때 10시가 되면 기도 화면과 알림을 띄웁니다.

> 앱이 꺼져 있어도 교회에서 직접 푸시를 보내려면 푸시 서버(예: Firebase Cloud Messaging)가 필요합니다.
> `sw.js`에 푸시 수신 코드가 이미 들어 있어 나중에 연결할 수 있습니다.

## 내용 바꾸기 (관리자)

코드를 몰라도 GitHub 웹사이트에서 `data` 폴더의 파일만 고치면 됩니다. 파일을 열고 ✏️(연필) → 수정 → **Commit changes**.

| 파일 | 내용 | 언제 |
|---|---|---|
| `data/sermons.json` | 설교 (맨 위가 '이번 주 말씀') | 매주 |
| `data/qt.json` | 날짜별 QT 본문·질문 | 매일/매주 |
| `data/prayers.json` | 공동 기도제목 | 수시 |
| `data/news.json` | 공지사항, 일정 | 수시 |
| `data/bulletins.json` + `bulletins/날짜/` | 주보 사진·PDF | 매주 |
| `data/gallery.json` + `photos/날짜/` | 행사 앨범 사진 | 수시 |
| `data/church.json` | 교회 이름, 주소, 예배 시간, 기도 시간, 암송 말씀, 유튜브 | 처음 한 번 |

- **주보·사진 올리기 (맥에서)**: 사진은 크기를 줄여서 넣어야 앱이 빠릅니다. `tools/add_images.py`가 줄이기와 json 기록을 한 번에 합니다.
  - 주보: `python3 tools/add_images.py bulletin 2026-11-01 주보1.jpg 주보2.jpg` (PDF도 함께 넣을 수 있음)
  - 앨범: `python3 tools/add_images.py album 2026-10-26 사진들... --title "가을 특별새벽기도회"`
  - 그다음 GitHub Desktop에서 Commit → Push. 한글(hwp) 주보는 PDF나 사진으로 저장해서 넣어 주세요.
- 성경 본문 위치는 `"passage": { "book": "eph", "chapter": 5, "from": 8, "to": 14 }` 형식입니다. 책 코드는 `js/bible.js`에 있습니다 (예: 창세기 `gen`, 시편 `psa`, 마태복음 `mat`, 요한복음 `joh`).
- 유튜브 영상은 주소 `https://www.youtube.com/watch?v=XXXX`의 `XXXX`를 `youtubeId`에 넣습니다.
- 지금 들어 있는 내용 중 **(예시)** 라고 적힌 것은 모두 실제 내용으로 바꿔 주세요.
- 기도 시간을 바꾸면 `prayer-alarm.ics`의 `DTSTART` 시간도 같이 바꿔 주세요.

## 배포 (GitHub Pages, 무료)

1. 저장소 **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: `main` / `/ (root)` → Save
3. 잠시 후 `https://ansanhatbit.com` 주소로 열립니다 (도메인은 Cloudflare에서 관리, 저장소의 `CNAME` 파일). 이 주소를 성도들에게 공유하세요.

## 내 컴퓨터에서 미리 보기

```bash
python -m http.server 8765
```

브라우저에서 `http://localhost:8765` 를 엽니다. (파일을 더블클릭해서 열면 데이터가 불러와지지 않습니다.)

## 참고

- 영어 성경: 성경 화면의 **English** 탭과 설교·QT의 **🇺🇸 영어로 보기**는 **ESV**를 앱 안에서 바로 보여 줍니다 ([Crossway ESV API](https://api.esv.org), 교회·비영리 무료).
  - **처음 한 번 설정**: [api.esv.org](https://api.esv.org)에서 API 키 받기 → Cloudflare에 `tools/esv-worker.js` 로 Worker 만들기 → Worker의 Secret `ESV_API_KEY`에 키 넣기 → Worker 주소를 `data/church.json`의 `"esvProxy"`에 넣기. 주소가 비어 있으면 대신 World English Bible(퍼블릭 도메인)을 보여 줍니다.
  - ESV 키는 공개 저장소에 넣지 않습니다. Worker 안에만 비밀로 보관되고, Worker는 우리 앱 주소(`ALLOWED_ORIGINS`)에서 온 요청만 받습니다. 도메인을 바꾸면 이 목록에 새 주소를 추가하세요.
  - ESV 사용 조건: 광고·유료 기능을 넣지 않기, 한 화면에 500절 또는 책의 절반 이상 보여 주지 않기(앱은 한 번에 한 장씩만 보여 줌), 본문에 ESV 표기와 저작권 문구 표시(앱이 자동으로 표시).
  - NIV는 Biblica의 허락 없이는 앱에 넣을 수 없어 사용하지 않습니다.
- 한글 듣기 (한글 화면): 휴대폰 내장 한국어 음성으로 개역한글을 읽습니다. 읽는 절이 표시되고, 절을 누르면 그 절부터, 장이 끝나면 다음 장으로 이어집니다. 속도 조절 가능.
- 영어 듣기 (English 화면)
  - **🎧 사람 낭독**: LibriVox 자원봉사자들이 녹음한 KJV 낭독(퍼블릭 도메인, archive.org에서 재생). 이때 화면 본문도 KJV로 바뀌어 듣는 내용과 같습니다. 66권 중 52권에 녹음이 있고, 녹음 하나가 여러 장을 묶어 읽는 경우가 많습니다. 녹음이 끝나면 다음 장으로 이어집니다.
  - 녹음이 없는 14권(여호수아, 열왕기하, 이사야, 예레미야애가, 호세아–말라기)은 자동으로 **🤖 휴대폰 음성**으로 읽습니다.
  - **🤖 휴대폰 음성**: 휴대폰 내장 음성(TTS)으로 WEB 본문을 읽습니다. 속도 조절, 절을 누르면 그 절부터 읽기.
  - 낭독 목록은 `python tools/build_audio_map.py`로 다시 만들 수 있습니다 (`data/audio-kjv.json`).
- 한글 본문은 개역한글(저작권 만료)을 `data/kor/<책>.json`에 담아 앱 안에서 바로 보여 줍니다. 한 번 읽은 책은 오프라인에서도 열립니다. 원본은 대한성서공회 공개본과 대조 검수된 [Korean-Bible-1961-KRV](https://github.com/bluesaurel/Korean-Bible-1961-KRV)이고, `python tools/build_korean_text.py`로 다시 만들 수 있습니다. 개역개정을 넣으려면 대한성서공회의 사용 허락이 필요합니다.
- QT 노트, 나의 기도 제목, 통독 기록은 각자의 휴대폰에만 저장되며 교회나 다른 사람에게 전송되지 않습니다.
